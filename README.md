# 看漫画 · 正式版本

这里仅提供 Android 正式安装包、更新说明和校验文件。源码仓库保持私有。

支持漫画柜、Mangabz 和 Komiic.cc，可在“发现”页顶部切换。收藏与阅读进度保存在本机，不同来源分别记录。

请从 [最新正式版本](https://github.com/nicholashyang/kanmanhua-releases/releases/latest) 下载 `kanmanhua-版本.apk`，按 Android 系统提示安装。支持 Android 8.0 及以上。

0.4.0 及以上版本可在“设置 → 检查 App 更新”中升级。0.3.0 及更早版本需要先手动安装最新正式 APK；沿用既有包名和签名，可保留收藏、阅读进度与设置。

每个正式版本提供 APK、`update.json` 和 `SHA256SUMS`。应用内更新会校验安装包哈希、包名、版本和签名。
